# Studies salvage campaign folder

## Files

| File | Holds |
| --- | --- |
| `plan.md` | Goal, exit criterion, repositories, governing skills, rulings, claims, release bar, stops, open decisions, deferrals, ROADMAP triggers, § State, § Sequence |
| `ledger.md` | One row per dispatched unit and per user ruling |
| `designs/contracts.md` | The `createOllamaFixture` contract, and Study's install, runner, rehearsal, and smaller additions |
| `designs/split.md` | Agent's records and compaction split |

## Read order

1. `plan.md` § State, then § Sequence.
2. The design that governs the first open unit.
3. `ledger.md`, for who ran what.

## Ids

- Units keep their ids for life: U0 to U8, U4a and U4b, U5a to U5c, A1, U7c, and U7d.
- Claims keep their numbers for life, 1 to 17. A retired claim's number is never reused.
